# Historical-Evolution-of-FIFA-World-Cups-A-Data-Analytics-Approach
Analytics project based on the original dataset "A Comprehensive Database on the FIFA World Cup" by Josh Fjeslstul (avaliable on: https://www.kaggle.com/datasets/joshfjelstul/world-cup-database), updating Matches, Stadiums, Teams and Tournaments tables, followed by SQL views, queries and interactive Power BI dashboards.
